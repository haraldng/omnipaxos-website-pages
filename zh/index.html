OmniPaxos

OmniPaxos 是一个 Rust 语言实现的分布式日志库

快速起步

Open-source Apache 2.0 Licensed. GitHub

宗旨 #

OmniPaxos 是一个软件库，旨在简化分布式系统的复制和容错，这在构建高可用服务时是一个具有挑战性的任务。我们的目标是通过提供完整的工具和抽象来赋能开发者，从而使得构建可靠、容错和一致的系统变得更加容易。通过 OmniPaxos，开发者不再需要担心复制和一致性算法 (consensus) 的复杂性；我们提供了一个 API，使得复制变得像操作仅追加日志一样简单。

功能亮点 #

Log API 👨‍💻

OmniPaxos提供了一个API, 令复制日志的使用像使用仅追加日志一样简单。

可恢复的 🏰

凭借OmniPaxos在集群中容忍连接问题的能力,体验最先进的容错能力。

即插即用 🔌

通过提供您自己的存储和网络实现，或使用我们提供的存储或网络实现，将OmniPaxos无缝集成到您的系统中。

灵活的一致性 🤸‍♀️

支持具有不同一致性级别的各种操作，以满足不同的应用程序的需求。

可定制的 🎨

以适合您应用程序的客制化法定节点数和领导职位来定制复制服务。

数据感知 🧠

[即将推出]使用从数据趋势和格式中学习的前沿复制技术来实现高效复制。
